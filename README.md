## 📊 项目详情

### 1. 基金对比分析器

**功能亮点：**
- 核心指标对比：累计收益、年化收益、波动率、夏普比率、最大回撤
- 净值走势对比：多只基金净值曲线可视化
- 收益-风险分布：散点图展示收益与风险的关系
- 回撤分析：历史回撤走势对比
- 收益率分布：日收益率分布直方图

**技术栈：** Python + Streamlit + Pandas + Plotly

**适用人群：** 基金投资者、理财顾问、金融专业学生

---

### 2. 投资组合模拟器

**功能亮点：**
- 资产配置：调整股票、债券、现金、商品、REITs的配置比例
- 净值模拟：基于历史参数模拟投资组合净值走势
- 收益分析：年度收益分布、月度收益热力图
- 风险分析：最大回撤、亏损概率、VaR
- 投资建议：根据配置给出组合类型判断

**技术栈：** Python + Streamlit + Pandas + Numpy + Plotly

**适用人群：** 投资者、资产配置研究者、金融从业者

---

### 3. 财务指标计算器

**功能亮点：**
- 盈利能力指标：毛利率、营业利润率、净利率、ROE
- 偿债能力指标：流动比率、速动比率、资产负债率、权益乘数
- 运营能力指标：总资产周转率、存货周转率、应收账款周转率、ROA
- 杜邦分析：ROE分解为三个驱动因素
- 现金流分析：现金流比率、现金流/营收、现金流/净利润
- 综合评价：100分制评分系统

**技术栈：** Python + Streamlit + Pandas + Numpy

**适用人群：** 财务分析师、投资者、审计人员、金融专业学生
