# 📊 基金对比分析器

对比多只基金的历史表现、风险收益特征，帮你做出更明智的投资决策。

![Python](https://img.shields.io/badge/Python-3.8+-blue?logo=python)
![Streamlit](https://img.shields.io/badge/Streamlit-1.28+-red?logo=streamlit)

## ✨ 功能特点

- 📈 **核心指标对比**：累计收益、年化收益、波动率、夏普比率、最大回撤
- 📉 **净值走势对比**：多只基金净值曲线可视化
- 🎯 **收益-风险分布**：散点图展示收益与风险的关系
- 📊 **回撤分析**：历史回撤走势对比
- 📊 **收益率分布**：日收益率分布直方图

## 🚀 快速开始

```bash
pip install -r requirements.txt
streamlit run fund_analyzer.py
```

## 📝 说明

本工具使用模拟数据演示功能，实际使用时可接入天天基金API或其他数据源获取真实数据。
