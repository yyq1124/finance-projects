# 💼 投资组合模拟器

模拟不同资产配置的投资组合表现，找到最适合你的风险收益平衡点。

![Python](https://img.shields.io/badge/Python-3.8+-blue?logo=python)
![Streamlit](https://img.shields.io/badge/Streamlit-1.28+-red?logo=streamlit)

## ✨ 功能特点

- ⚖️ **资产配置**：调整股票、债券、现金、商品、REITs的配置比例
- 📈 **净值模拟**：基于历史参数模拟投资组合净值走势
- 📊 **收益分析**：年度收益分布、月度收益热力图
- ⚠️ **风险分析**：最大回撤、亏损概率、VaR
- 💡 **投资建议**：根据配置给出组合类型判断

## 🚀 快速开始

```bash
pip install -r requirements.txt
streamlit run portfolio_simulator.py
```

## 📝 说明

- 本模拟基于历史数据和假设，不代表未来实际收益
- 投资有风险，入市需谨慎
- 建议根据个人风险承受能力和投资目标做出决策
